# Política de segurança

Este repositório publica o portfólio pessoal de Bruno. Não abra uma issue pública para relatar uma vulnerabilidade que possa expor dados ou permitir execução de código.

Envie um relato privado pelo [GitHub Security Advisories](https://github.com/brunosrz/brunosrz/security/advisories/new), incluindo os passos para reproduzir, o impacto e uma sugestão de mitigação quando possível. Não inclua credenciais válidas no relato; revogue-as e compartilhe apenas evidências sanitizadas.

Segredos de deploy devem ficar no gerenciador de segredos do provedor escolhido. Nunca adicione arquivos `.env` ou tokens ao Git, logs de CI ou capturas de tela.
